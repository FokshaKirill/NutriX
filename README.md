# NutriX

**Веб-приложение для планирования питания** — удобный инструмент для составления персональных рационов, расчёта БЖУК и контроля питания.

## О проекте

NutriX — это веб-платформа, которая помогает пользователям:
- Составлять сбалансированные рационы питания
- Рассчитывать калорийность и макронутриенты (БЖУК)
- Работать с базой продуктов и рецептов
- Планировать приёмы пищи на день/неделю
- Получать данные о продуктах из популярных магазинов

## Основные возможности

- **Каталог продуктов** с подробной нутрициологической информацией
- **Конструктор рецептов** и готовые блюда
- **Планировщик рационов** (Meal Plan)
- **Автоматический парсинг** продуктов из магазинов (Vkusvill, Price.ru и др.)
- **Система авторизации** (регистрация, вход, управление профилем)
- **Личный кабинет** пользователя

## Технологический стек

- **Backend**: .NET 8, C#
- **Архитектура**: Clean Architecture (Layered)
- **База данных**: PostgreSQL + Entity Framework Core
- **Frontend**: ASP.NET MVC + Razor Pages + SCSS
- **Дополнительно**: Background parsing, Repository Pattern, Dependency Injection

## Структура проекта

- **Domain** — доменные сущности и бизнес-правила
- **Infrastructure** — работа с БД, репозитории, миграции
- **Services** — бизнес-логика
- **Presentation** — веб-приложение (Controllers, Views)

## Что уже реализовано

- Полноценная многослойная архитектура
- Модели продуктов, рецептов, планов питания
- CRUD-операции для основных сущностей
- Система аутентификации и авторизации
- Двухфазный скрапер продуктов
- Административные контроллеры для парсинга
- База данных и миграции

---

**Проект находится в активной разработке** (ветка `develop`).

## Цель проекта

Разработка полнофункционального веб-приложения для персонализированного планирования питания с возможностью автоматического пополнения базы продуктов из открытых источников.
